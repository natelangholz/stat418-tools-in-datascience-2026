# NASA Web Server Log Analysis — Sayalee Damle

Analysis of NASA Kennedy Space Center web server logs from July and August 1995.

## Scripts

| Script | Purpose |
|--------|---------|
| `download_data.sh` | Downloads both log files, validates size/line count, and creates a timestamped backup |
| `analyze_logs.sh` | Runs 12 analyses on a single log file (pass as argument) |
| `generate_report.sh` | Runs analysis on both logs and writes `REPORT.md` |
| `run_pipeline.sh` | Master script — runs all stages in order, handles errors, and cleans up |

## Quick Start

Run the full pipeline from scratch:

```bash
cd week-2/assignment-1/submissions/sayaleedamle
./run_pipeline.sh
```

If you already have the log files and want to skip the download:

```bash
./run_pipeline.sh --skip-download
```

Progress is printed to the terminal and also saved to `pipeline.log`.

## Running Scripts Individually

### Download log files

```bash
./download_data.sh
```

Downloads `NASA_Jul95.log` and `NASA_Aug95.log`, validates them (≥100 MB, ≥1 M lines each), and backs them up to a `backup_YYYYMMDD_HHMMSS/` directory. All operations are logged to `download.log`.

### Analyse a single log file

```bash
./analyze_logs.sh NASA_Jul95.log
./analyze_logs.sh NASA_Aug95.log
```

Prints 12 analysis sections to stdout. Redirect to a file to save results:

```bash
./analyze_logs.sh NASA_Jul95.log > results_july.txt
```

**Analysis sections:**
1. Top 10 hosts (excluding 404 errors)
2. IP address vs hostname breakdown
3. Top 10 requested URLs (excluding 404 errors)
4. HTTP request methods
5. 404 error count
6. Response code breakdown
7. Peak hours (full hourly table + top 3 busiest / quietest)
8. Busiest day
9. Quietest day (excluding outage dates with < 100 requests)
10. Hurricane / data outage detection (gaps > 1 hour between entries)
11. Response size (largest, average, total count)
12. Error patterns (4xx/5xx by hour, by host, by code)

### Generate the markdown report

```bash
./generate_report.sh
```

Runs analysis on both log files internally and writes `REPORT.md`. The report includes:
- Summary statistics table comparing July vs August
- ASCII bar charts for hourly traffic and response code distribution
- All 12 analysis sections for each month
- Key findings and anomalies section

## Output Files

| File | Description |
|------|-------------|
| `REPORT.md` | Final markdown report (generated by `generate_report.sh`) |
| `pipeline.log` | Timestamped log of every pipeline stage |
| `download.log` | Timestamped log of download and validation steps |

## Requirements

- `bash` 3.2+
- `curl` (for `download_data.sh`)
- `awk`, `sed`, `sort`, `uniq` (standard on macOS and Linux)
- `gawk` recommended for outage detection (Section 10 uses `mktime`)

## Testing with a Sample

```bash
head -1000 NASA_Jul95.log > test_sample.log
./analyze_logs.sh test_sample.log
rm test_sample.log
```
