# NASA Web Log Analysis

## Overview

We compare NASA web logs from July and August 1995.

---

## Traffic

July: 1,891,715 requests  
August: 1,569,898 requests  

Traffic dropped in August.

IP access increased:
- July: 22.16%
- August: 28.44%

More direct access in August.

---

## Responses

Most responses are 200:

- July: 89.95%
- August: 89.11%

Very similar.

404 errors:
- July: 10,845
- August: 10,056

Slight decrease in August.

---

## Time patterns

Busiest hour:
- July: 14
- August: 15

Busiest day:
- July: 13/Jul
- August: 31/Aug

August has clearer variation between busy and quiet days.

---

## Hosts

Top hosts are mostly:

- prodigy.com
- nasa.gov
- aol proxies (in August)

August shows more proxy traffic.

---

## URLs

Most requests are images:

- NASA logos
- KSC logos

Users repeatedly load the same assets.

---

## Insight

July has higher traffic and more hostname-based access.

August has lower traffic but more IP and proxy access.

It looks like usage shifted, not the system.

---

## Conclusion

System behavior is stable:

- ~90% success rate
- similar patterns

Main change is how users access the site, not performance.
