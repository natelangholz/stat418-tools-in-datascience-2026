Visit `/docs` for the interactive API documentation.

**Predictors Used:**
- `wt` — weight of the car (1000 lbs)
- `hp` — gross horsepower
- `cyl` — number of cylinders (4, 6, or 8)
- `vs` — engine shape (0 = V-shaped, 1 = straight)
